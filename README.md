# CanvasCord

CanvasCord is a self-hostable, real-time communication platform for artists,
creators, and hobbyists.

## Core Features

- Real-time text messaging
- Voice channels and voice notes
- Image, artwork, and video sharing
- Typing indicators and online presence
- Read receipts and unread tracking
- Customizable, white-label communities

## Technology Stack

- Frontend: React 18, TypeScript, Tailwind CSS
- Backend: Node.js, Express.js, Socket.IO
- Database: MongoDB with Mongoose
- Real-time coordination: Redis
- Object storage: AWS S3
- State management: Zustand, TanStack Query
- Infrastructure: Docker, GitHub Actions

## Project Structure

- `frontend/` — React application
- `backend/` — REST API and WebSocket server
- `infrastructure/` — Docker and deployment configuration
- `docs/` — Architecture and development documentation
